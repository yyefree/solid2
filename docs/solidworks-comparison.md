# Solid2 与 SolidWorks 界面差异详细比对

> 目标：逐区域对照 Solid2 当前复刻与真实 SolidWorks（2020+ 默认界面）的 GUI 差异，标注严重程度，并给出改进清单。
> 严重程度：🔴 高（一眼能看出不像）/ 🟡 中（细节不对）/ 🟢 低（可接受或已接近）。

## 2. 逐区域详解

### 2.1 菜单栏（Menu Bar）
- **SW**：最左是 SOLIDWORKS 应用菜单按钮（"S" 标志或汉堡），随后是 `文件 编辑 视图 插入 工具 窗口 帮助` 七个带下划线的菜单，最右是「搜索命令」框与「选项」「帮助」按钮。菜单下方通常还有一条 **Standard 工具栏**（新建/打开/保存/打印/撤销/重做/重建/选项/帮助 图标）。
- **Solid2**：七菜单（Alt 助记符）+ 品牌 "S" 按钮（弹出新建/打开/保存/…）+ 搜索框；下方一行 Standard 工具栏（新建/打开/保存 | 撤销/重做/重建 | 选项/帮助）。
- **差异**：🟢 已一致。

### 2.2 CommandManager（Ribbon）
- **SW 默认页签**：特征(Features) / 草图(Sketch) / 评估(Evaluate) / DimXpert / 装配体(Assembly) / 工程图(Drawing)，并可在右键菜单里显示/隐藏 钣金、模具工具、曲面 等页签。组之间有竖线、组标题在**底部**，大按钮 32px + 文字标签。
- **Solid2**：已实现 特征/草图/评估/装配体/工程图 + 自定义 曲线/视图/AI。组标题在底部、竖线分隔、大/小按钮；零件模式下默认激活「特征」页签（与 SW 一致）。
- **差异**：🟢 "曲线/视图/AI" 为产品自定义页签（合理，但非 SW 原生）。评估页签含 质量属性（OCCT 精确积分）/ 测量（SW 式常驻对话框，见 §2.7）/ 模型统计 / 几何检查；SW 的 截面属性 暂缺。

### 2.3 Heads-up 视图工具栏
- **SW（从左到右）**：视图定向 ▾ / 显示样式 ▾ / 隐藏/显示 ▾ / 外观(编辑外观) ▾ / 布景 ▾ / 光源 ▾ / **整屏显示** / 缩放至区域 ▾ / 放大 / 缩小 / **剖面视图** ▾ / RealView / **上一视图** / 旋转视图 ▾。
- **Solid2**：已按 SW 顺序重排为 14 个——视图定向 · 显示样式 · 隐藏/显示项目 · 编辑外观（9 色板）· 应用布景 · 光源（5 预设）· 整屏显示 · 缩放至区域 · 放大 · 缩小 · 剖面视图 · **RealView（RoomEnvironment 预过滤环境反射，按钮切换 scene.environment）** · 上一视图 · 旋转视图（切换式临时模式）。
- **差异**：🟢 已与 SW 一致（SW 的「视图设置/透·正交切换」不属于 heads-up 按钮，已按此为据把「视图设置」「显示模式」撤出 heads-up；投影切换保留在视图设置对话框，Standard 工具栏「选项」与视图定向菜单「更多视图设置…」均可打开）。

### 2.4 ViewCube + Compass
- **SW**：右上角 ViewCube（6 面/8 角/12 棱，点击切标准视图），**下方叠加一个圆形指北罗盘**（N/E/S/W + 30° 刻度环），拖动罗盘可绕竖直轴旋转模型。
- **Solid2**：ViewCube 6 面/8 角/12 棱热区 + 主页；外围已叠加可拖动旋转的指北罗盘（N/E/S/W + 30° 刻度）。
- **差异**：🟢 已一致。

### 2.5 参考三重轴
- **SW**：图形区左下角圆盘 + X(红)/Y(绿)/Z(蓝) 三轴，轴端有颜色文字标签，随相机实时投影、朝向观察者的轴加粗。
- **Solid2**：已实现且高度一致。🟢 仅细节（圆盘底色/标签描边）可微调。

### 2.6 特征管理器设计树
- **SW 零件树（自上而下）**：
  ```
  零件1
  ├ 注解
  ├ 材质 <未指定>
  ├ 实体（实体）        ← 仅当有实体
  ├ 曲面实体            ← 仅当有曲面
  ├ 基准面
  │   ├ 前视基准面
  │   ├ 上视基准面
  │   └ 右视基准面
  ├ 草图1               ← 草图与特征按创建顺序直接挂在根下
  ├ 凸台-拉伸1
  ├ 切除-拉伸1
  ├ 圆角1
  └ 原点
  ```
- **Solid2**：草图与特征已按创建顺序平铺为零件根的直接子节点（无"历史特征"汇总文件夹）；原点为可折叠文件夹，展开为 X/Y/Z 三个轴节点（带 SW 轴颜色文字标签）。
- **差异**：🟢 仅「曲面实体」文件夹未建（当前无曲面类特征，依赖曲面特征落地）。

### 2.7 属性管理器 / 任务窗格
- **SW 左侧**：顶部一排选项卡 `特征管理器设计树 | 属性管理器 | 配置管理器 | DimXpert 管理器 | 显示管理器`。当你编辑某个特征（如拉伸），**属性管理器**自动激活，显示该特征的参数（距离/方向/反向/拔模/薄壁…）+ 底部 ✓/✗ + 飞出菜单。
- **SW 右侧**：**任务窗格**（Task Pane），右边缘竖排选项卡：`SolidWorks 资源 | 设计库 | 文件浏览器 | 视图调色板 | 自定义属性 | 外观`，点击切换内容。
- **Solid2**：左侧三选项卡 `特征管理器 | 属性管理器 | 配置管理器`（选中/编辑特征时自动切到属性管理器）；特征对话框（拉伸/圆角/阵列/拔模/抽壳/弹簧/涡状线/缩放/镜像/孔/筋/参数表/表达式/测量等 24 处）全部经 `toast.modal({host:'pm'})` **内嵌渲染进属性管理器**：标题栏 + 参数字段 + 底部 取消/确定（✓/✗），**非模态**、无居中遮罩，Esc 或底部按钮关闭；与常规属性面板（feature 选中时的参数）共用左面板 body、互斥显示，关闭后原内容恢复。「测量」（评估 → 测量）也是常驻属性管理器对话框：随图形区选择**实时重算**，支持 顶点/边/面/圆/实体 组合（距离+ΔXYZ、面积、长度+半径直径圆心、最小距离+夹角、表面积+体积），最近 8 条测量历史自动累积。右侧为竖排选项卡任务窗格（资源/设计库/文件浏览器/视图调色板/自定义属性/外观）。
- **差异**：🟢 核心交互形态已复刻（SW 原生 DimXpert/钣金/模具页签为有意保留的产品自定义页签）。

### 2.8 状态栏
- **SW**：左=消息；中=可拖拽分隔；右=`Cursor: X Y Z` 坐标 + 单位 + **选择过滤器**(图标按钮组) + 重建图标 + **"有什么问题"**(若有错误)。状态栏最右还有单位/快速提示。
- **Solid2**：左 LED+消息；右 `Cursor:` 前缀坐标 + 单位(mm) + 过滤器下拉（全部/面/边/顶点/实体，真正 gate 选择）+ 重建 + What's Wrong（点击跳到出错特征）。
- **差异**：🟢 已一致（过滤器形态为下拉而非 SW 的图标按钮组；单位制切换暂缺，见第八轮说明）。

### 2.9 确认角
- **SW**：图形区**右下角**的小圆角方块，内含 ✓（确定）和 ✗（取消）。
- **Solid2**：已移至图形区右下角，SW 小圆角框样式，✓/✗ 已挂载（草图/特征编辑中激活）。🟢

### 2.10 右键上下文菜单
- **SW**：图形区右键 → 顶部 4 个**上下文快捷图标**（随选中对象变化：面→草图/圆角/倒角/测量；空白→视图定向/显示样式/剖面/整屏）→ 命令列表（带勾选/单选、子菜单 ▸、右侧快捷键文本）→ 底部"更多命令…"飞出。
- **Solid2**：已实现顶部 4 图标 + 命令列表 + 子菜单 + 勾选/单选 + 快捷键文本，底部"更多命令…"飞出（快捷键一览/视图设置/自定义/关于），面菜单含可用的「选择其他…」（枚举射线穿过的候选面，radio 切换）。🟢 结构一致。

### 2.11 S 快捷方式栏 / 鼠标手势 / 文档标签
- **S 快捷栏**：SW 是环形命令栏（可自定义分组），Solid2 是 4/8 扇形轮盘——语义一致、形态不同。🟢
- **鼠标手势**：SW 默认 8 向，Solid2 已实现 8 向。🟢
- **文档标签**：SW 图形区底部有文档标签栏（多文档切换）。Solid2 已实现：标签 = 打开的文档（图标 + 名称），点击切换、「+」新建（零件/装配体/工程图三选一）、右键菜单（激活/关闭/关闭其他）。条目持有 CadDocument 实例、ModelResult、独立 undo/redo 栈与相机快照——切换只是换引用，切回时几何/参数/名称计数器/撤销历史全部原样恢复，不序列化不重建。🟢（已知限制：保存/打开仍只作用于当前文档。）

### 2.12 热键与鼠标映射
- 已按 SW 默认映射实现（`hotkeys.ts` 单一来源，菜单/帮助/分发三处共用），基本一致。🟢
- 鼠标：中键旋转、Ctrl+中键平移、Shift+中键缩放、滚轮缩放、右键手势、左键选择——与 SW 一致。🟢

## 3. 改进清单（按优先级）

### 本轮已实施 ✅

#### 第一轮（界面复刻）
1. **ViewCube + Compass 罗盘**：在视图立方周围叠加可拖动旋转的指北罗盘（N/E/S/W + 30° 刻度）。
2. **确认角移至右下角** 并改为 SW 小圆角框样式。
3. **特征树重构**：去掉"历史特征"文件夹，草图与特征按创建顺序平铺为零件根的直接子节点；保留 注解/材质/实体/基准面/原点 并可折叠。
4. **左面板三选项卡**：特征管理器 / 属性管理器 / 配置管理器（编辑特征时属性管理器自动激活）。
5. **右面板改为任务窗格**：右侧竖排选项卡（SolidWorks 资源 / 设计库 / 文件浏览器 / 视图调色板 / 自定义属性）。
6. **CommandManager 默认页签**：零件模式下默认激活"特征"。
7. **状态栏**：新增「What's Wrong」错误指示（点击跳到出错特征）+ 选择过滤器下拉（全部/仅面/仅边，真正 gate `selectFace`/`selectEdge`，默认 `all` 不影响既有选择）。
8. **Heads-up 工具栏重排** 为 SolidWorks 从左到右顺序（视图定向/显示样式/隐藏·显示/布景/剖面 → 整屏显示/缩放至区域/上一视图 → 视图设置/显示模式），并新增 **放大 / 缩小** 按钮（`viewport.zoomBy`）。
9. **Standard 工具栏**：菜单栏下方一行（新建/打开/保存/打印 | 撤销/重做/重建 | 选项/帮助）。
10. **文档标签栏**：图形区底部 零件 / 装配体 / 工程图 切换卡（`app.setMode`）。

#### 第二轮（视图工具补齐）
11. **Heads-up 新增「旋转视图」**：切换式临时模式，模式内左键拖动即旋转（复用 OrbitControls 的中键旋转映射），Esc 或再次点击退出；按钮带激活态高亮。
12. **Heads-up 新增「编辑外观」**：9 色色板（默认灰/红/蓝/绿/黄/橙/紫/白/黑），下拉项带色块（`PopupItem.color`，popup.ts 渲染色片），经 `app.setAppearance` 更换零件颜色；重建与 STEP 导入模型时保持所选外观。
13. **Heads-up 新增「光源」**：5 组预设（默认/明亮/柔和/顶光/背光），分别调整半球光与主光/补光/轮廓光的强度与位置（`viewport.setLightPreset`）。
14. **状态栏增强**：光标坐标加 `Cursor:` 前缀（对齐 SolidWorks 状态栏格式）；选择过滤器补 **顶点**（就近 8px 像素级拾取 + 选中的顶点以像素尺寸点高亮）。

#### 第三轮（对齐 §2.x 节细节差距）
15. **Heads-up 按 §2.3 节精确顺序重排**为 13 按钮，并撤出 SW 没有的「视图设置」「显示模式」按钮（投影切换保留在视图设置对话框，Standard 工具栏「选项」/ 视图定向菜单「更多视图设置…」均可打开）。
16. **品牌按钮 SW 化**：红色 S 方块（SW 品牌红 #e0392b → #a52218 渐变）。
17. **特征树原点项**改为可折叠文件夹，展开为 X/Y/Z 三个轴节点（SW 零件树原点结构）。
18. **右键菜单补齐**：四组上下文菜单（空白/面/边/草图）底部加「更多命令…」飞出（快捷键一览/视图设置/自定义/关于）；面菜单「选择其他…」实现为可用功能（`app.pickCandidateFaces` 枚举射线穿过的候选面，radio 切换重选）。

#### 第四轮（RealView 图形）
19. **Heads-up 新增「RealView」**：用 three.js RoomEnvironment + PMREMGenerator 预过滤环境贴图，
   按钮切换 `viewport.scene.environment` 给实体材质加环境反射（默认不挂，保持经典 CAD 外观）；
   LineBasic/Basic 材质（网格/基准面/边线）不受影响。至此 §2.3 节 Heads-up 与 SW 完全一致（14 按钮）。

#### 第五轮（选择过滤器补齐）
20. **选择过滤器补「实体」**：`buildMeshResult` 按 bodiesOf 顺序逐 body 用 `IsSame` 比对面，
   给 `FaceMeta` 标 `bodyIndex`（多实体时）；主线程 filter='body' 时命中的面反查 bodyIndex →
   `selectBody` 选中整个实体（高亮该实体全部面），selectFace/selectEdge 门控拒绝。
   至此状态栏过滤器含 SW 全部选项（全部/面/边/顶点/实体）。
#### 第六轮（多文档）
21. **多文档标签栏**：`DocumentEntry` 持有 CadDocument 实例 + ModelResult + imported/assembly/drawing +
   独立 undo/redo 栈 + 相机快照；`newDocument / activateDocument / closeDocument` 只换引用。
   undo/redo/openProject/loadFeatures/newProject/importStep/rebuild 全部换 doc 路径同步条目，保证条目不失步；
