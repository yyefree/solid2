# Solid2 与 SolidWorks 界面差异详细比对

> 目标：逐区域对照 Solid2 当前复刻与真实 SolidWorks（2020+ 默认界面）的 GUI 差异，标注严重程度，并给出改进清单。
> 严重程度：🔴 高（一眼能看出不像）/ 🟡 中（细节不对）/ 🟢 低（可接受或已接近）。

---

## 2. 逐区域详解

### 2.1 菜单栏（Menu Bar）
- **SW**：最左是 SOLIDWORKS 应用菜单按钮（"S" 标志或汉堡），随后是 `文件 编辑 视图 插入 工具 窗口 帮助` 七个带下划线的菜单，最右是「搜索命令」框与「选项」「帮助」按钮。菜单下方通常还有一条 **Standard 工具栏**（新建/打开/保存/打印/撤销/重做/重建/选项/帮助 图标）。
- **Solid2**：七菜单（Alt 助记符）+ 品牌 "S" 按钮（弹出新建/打开/保存/…）+ 搜索框；下方一行 Standard 工具栏（新建/打开/保存 | 撤销/重做/重建 | 选项/帮助）。
- **差异**：🟢 已一致。

### 2.2 CommandManager（Ribbon）
- **SW 默认页签**：特征(Features) / 草图(Sketch) / 评估(Evaluate) / DimXpert / 装配体(Assembly) / 工程图(Drawing)，并可在右键菜单里显示/隐藏 钣金、模具工具、曲面 等页签。组之间有竖线、组标题在**底部**，大按钮 32px + 文字标签。
- **Solid2**：已实现 特征/草图/**曲面**/评估/装配体/工程图 + 自定义 曲线/视图/AI。组标题在底部、竖线分隔、大/小按钮；零件模式下默认激活「特征」页签（与 SW 一致）。
- **差异**：🟢 "曲线/视图/AI" 为产品自定义页签（合理，但非 SW 原生）。曲面页签含 拉伸曲面/旋转曲面/平面区域（生成**曲面实体**，见 §2.14）；评估页签含 质量属性（OCCT 精确积分）/ 测量（SW 式常驻对话框，见 §2.7）/ 截面属性（基准面 + 沿法向偏移，网格切片实时算面积/质心/惯性矩/主方向/回转半径，见 §2.13）/ 模型统计 / 几何检查，已与 SW 评估页签对齐。

### 2.3 Heads-up 视图工具栏
- **SW（从左到右）**：视图定向 ▾ / 显示样式 ▾ / 隐藏/显示 ▾ / 外观(编辑外观) ▾ / 布景 ▾ / 光源 ▾ / **整屏显示** / 缩放至区域 ▾ / 放大 / 缩小 / **剖面视图** ▾ / RealView / **上一视图** / 旋转视图 ▾。
- **Solid2**：已按 SW 顺序重排为 14 个——视图定向 · 显示样式 · 隐藏/显示项目 · 编辑外观（9 色板）· 应用布景 · 光源（5 预设）· 整屏显示 · 缩放至区域 · 放大 · 缩小 · 剖面视图 · **RealView（RoomEnvironment 预过滤环境反射，按钮切换 scene.environment）** · 上一视图 · 旋转视图（切换式临时模式）。
- **差异**：🟢 已与 SW 一致（SW 的「视图设置/透·正交切换」不属于 heads-up 按钮，已按此为据把「视图设置」「显示模式」撤出 heads-up；投影切换保留在视图设置对话框，Standard 工具栏「选项」与视图定向菜单「更多视图设置…」均可打开）。

### 2.4 ViewCube + Compass
- **SW**：右上角 ViewCube（6 面/8 角/12 棱，点击切标准视图），**下方叠加一个圆形指北罗盘**（N/E/S/W + 30° 刻度环），拖动罗盘可绕竖直轴旋转模型。
- **Solid2**：ViewCube 6 面/8 角/12 棱热区 + 主页；外围已叠加可拖动旋转的指北罗盘（N/E/S/W + 30° 刻度）。
- **差异**：🟢 已一致。

### 2.5 参考三重轴
- **SW**：图形区左下角圆盘 + X(红)/Y(绿)/Z(蓝) 三轴，轴端有颜色文字标签，随相机实时投影、朝向观察者的轴加粗。
- **Solid2**：已实现且高度一致。🟢 仅细节（圆盘底色/标签描边）可微调。

### 2.6 特征管理器设计树
- **SW 零件树（自上而下）**：
  ```
  零件1
  ├ 注解
  ├ 材质 <未指定>
  ├ 实体（实体）        ← 仅当有实体
  ├ 曲面实体            ← 仅当有曲面
  ├ 基准面
  │   ├ 前视基准面
  │   ├ 上视基准面
  │   └ 右视基准面
  ├ 草图1               ← 草图与特征按创建顺序直接挂在根下
  ├ 凸台-拉伸1
  ├ 切除-拉伸1
  ├ 圆角1
  └ 原点
  ```
- **Solid2**：草图与特征已按创建顺序平铺为零件根的直接子节点（无"历史特征"汇总文件夹）；「实体」「曲面实体」文件夹按需出现（有实体/曲面时）；原点为可折叠文件夹，展开为 X/Y/Z 三个轴节点（带 SW 轴颜色文字标签）。
- **差异**：🟢 已与 SW 结构一致（含「曲面实体」文件夹，由曲面特征产生）。

### 2.7 属性管理器 / 任务窗格
- **SW 左侧**：顶部一排选项卡 `特征管理器设计树 | 属性管理器 | 配置管理器 | DimXpert 管理器 | 显示管理器`。当你编辑某个特征（如拉伸），**属性管理器**自动激活，显示该特征的参数（距离/方向/反向/拔模/薄壁…）+ 底部 ✓/✗ + 飞出菜单。
- **SW 右侧**：**任务窗格**（Task Pane），右边缘竖排选项卡：`SolidWorks 资源 | 设计库 | 文件浏览器 | 视图调色板 | 自定义属性 | 外观`，点击切换内容。
- **Solid2**：左侧三选项卡 `特征管理器 | 属性管理器 | 配置管理器`（选中/编辑特征时自动切到属性管理器）；特征对话框（拉伸/圆角/阵列/拔模/抽壳/弹簧/涡状线/缩放/镜像/孔/筋/参数表/表达式/测量等 24 处；**拉伸已升级为 SW 式**：起始条件（草图基准面 / 等距）+ 方向 1 终止条件（给定深度 / 成形到顶点 / 成形到面 / 完全贯穿 / 两侧对称）+ 方向 2（两侧不对称）+ 反向 + 拔模角 + **薄壁特征**（单向 / 两侧对称 / 两侧不对称 + 厚度，开环轮廓偏置成带、闭环偏置成环带），见 §3 第十三/十四轮）全部经 `toast.modal({host:'pm'})` **内嵌渲染进属性管理器**：标题栏 + 参数字段 + 底部 取消/确定（✓/✗），**非模态**、无居中遮罩，Esc 或底部按钮关闭；与常规属性面板（feature 选中时的参数）共用左面板 body、互斥显示，关闭后原内容恢复。「测量」（评估 → 测量）也是常驻属性管理器对话框：随图形区选择**实时重算**，支持 顶点/边/面/圆/实体 组合（距离+ΔXYZ、面积、长度+半径直径圆心、最小距离+夹角、表面积+体积），最近 8 条测量历史自动累积。右侧为竖排选项卡任务窗格（资源/设计库/文件浏览器/视图调色板/自定义属性/外观）。
- **差异**：🟢 核心交互形态已复刻（SW 原生 DimXpert/钣金/模具页签为有意保留的产品自定义页签）。

### 2.8 状态栏
- **SW**：左=消息；中=可拖拽分隔；右=`Cursor: X Y Z` 坐标 + 单位 + **选择过滤器**(图标按钮组) + 重建图标 + **"有什么问题"**(若有错误)。状态栏最右还有单位/快速提示。
- **Solid2**：左 LED+消息；右 `Cursor:` 前缀坐标（随单位制换算）+ **单位制按钮**（MMGS/CGS/IPS 下拉切换，等同 SW 在状态栏显示单位系统并点击打开单位设置）+ 过滤器下拉（全部/面/边/顶点/实体，真正 gate 选择）+ 重建 + What's Wrong（点击跳到出错特征）。
- **差异**：🟢 已一致（过滤器形态为下拉而非 SW 的图标按钮组；单位制切换已实现——MMGS 公制 / CGS 厘米 / IPS 英制，状态栏点击切换或 工具 > 单位制 子菜单，全界面只读读出值联动换算：坐标、测量、质量属性、模型信息、工程图尺寸与公差、干涉体积）。

### 2.9 确认角
- **SW**：图形区**右下角**的小圆角方块，内含 ✓（确定）和 ✗（取消）。
- **Solid2**：已移至图形区右下角，SW 小圆角框样式，✓/✗ 已挂载（草图/特征编辑中激活）。🟢

### 2.10 右键上下文菜单
- **SW**：图形区右键 → 顶部 4 个**上下文快捷图标**（随选中对象变化：面→草图/圆角/倒角/测量；空白→视图定向/显示样式/剖面/整屏）→ 命令列表（带勾选/单选、子菜单 ▸、右侧快捷键文本）→ 底部"更多命令…"飞出。
- **Solid2**：已实现顶部 4 图标 + 命令列表 + 子菜单 + 勾选/单选 + 快捷键文本，底部"更多命令…"飞出（快捷键一览/视图设置/自定义/关于），面菜单含可用的「选择其他…」（枚举射线穿过的候选面，radio 切换）。🟢 结构一致。

### 2.11 S 快捷方式栏 / 鼠标手势 / 文档标签
- **S 快捷栏**：SW 是环形命令栏（可自定义分组），Solid2 是 4/8 扇形轮盘——语义一致、形态不同。🟢
- **鼠标手势**：SW 默认 8 向，Solid2 已实现 8 向。🟢
- **文档标签**：SW 图形区底部有文档标签栏（多文档切换）。Solid2 已实现：标签 = 打开的文档（图标 + 名称），点击切换、「+」新建（零件/装配体/工程图三选一）、右键菜单（激活/关闭/关闭其他）。条目持有 CadDocument 实例、ModelResult、独立 undo/redo 栈与相机快照——切换只是换引用，切回时几何/参数/名称计数器/撤销历史全部原样恢复，不序列化不重建。🟢（已知限制：保存/打开仍只作用于当前文档。）

### 2.12 热键与鼠标映射
- 已按 SW 默认映射实现（`hotkeys.ts` 单一来源，菜单/帮助/分发三处共用），基本一致。🟢
- 鼠标：中键旋转、Ctrl+中键平移、Shift+中键缩放、滚轮缩放、右键手势、左键选择——与 SW 一致。🟢

### 2.13 评估页签：截面属性（Section Properties）
- **SW**：评估 → 截面属性 打开 PropertyManager，选择 前视/上视/右视 基准面（或任意面/平面）+ 沿法向偏移量，
  实时显示该剖切平面截得截面的 面积 / 质心(X,Y) / 惯性矩(Ixx,Iyy,Ixy,Izz) / 主惯性矩(Ix1,Iy1) 与
  主方向角 / 回转半径(Rx,Ry)，多闭合环（含孔）自动合计。
- **Solid2**：已复刻为 SW 式常驻 PropertyManager（`src/ui/sectionprops-dialog.ts`）。选 前视/上视/右视 基准面 + 沿法向偏移输入（默认偏移 = 网格质心在法向上的投影，保证截面穿过零件）；结果表实时列出 面积 / 形心X / 形心Y / Ixx / Iyy / Ixy / Izz / Ix1 / Iy1 / 主方向 / 回转半径。几何算法置于纯模块 `src/core/sectionprops.ts`（不 `import` DOM/内核/three，可独立 Node 单测）：三角网格与平面求交 → 线段按端点量化键邻接缝合为闭合多边形（支持多实体外环 + 实体孔环）→ Green 定理算带符号面积/质心，按符号自动区分外环(+)/孔(-)叠加，平行轴定理平移到形心轴，主惯性矩由 2×2 惯性张量特征值分解（θ=½·atan2(−2Ixy, Ixx−Iyy)）。单位随单位制切换联动（`formatInertia` 用 volUnit 的 ³→⁴ 变体）。订阅 `app.on('change')` 与 `app.on('units')` 实时重算；入口：评估页签「截面属性」、工具菜单、S 快捷栏。
- **差异**：🟢 已与 SW 截面属性形态一致（SW 原生还支持任意面/平面剖切，当前仅基准面三向，足够覆盖常规定位；孔环与多实体合计已支持）。

### 2.14 曲面页签：曲面特征（Surface Features）
- **SW**：曲面页签提供 拉伸曲面 / 旋转曲面 / 扫描曲面 / 放样曲面 / 边界曲面 / 填充（平面区域）/ 偏移曲面 / 延展 / 裁剪 / 缝合 / 加厚 等。生成的**曲面实体**不参与实体布尔，单独列在设计树「曲面实体」文件夹；开放轮廓产生单侧曲面，闭合轮廓产生无盖侧壁。
- **Solid2**：已实现 曲面页签 + 五个核心曲面特征（`src/ui/surface-dialogs.ts` + `engine.ts`）：
  - **拉伸曲面**：草图轮廓沿法向拉伸成**壳**（不封顶）。闭合轮廓 → 四周侧壁；开放折线 → 单侧曲面。
  - **旋转曲面**：草图轮廓绕「轴起点→轴终点」（草图局部坐标）旋转成壳。
  - **平面区域**：闭合草图轮廓填成一个平面曲面。
  - **放样曲面**：多个草图截面蒙皮成壳（不封顶、不成实体），支持直纹面选项。
  - **扫描曲面**：轮廓草图沿路径草图扫成壳（不封顶），路径支持开放折线/弧串与闭环。
  几何走 `solid.ts` 的 `surfaceExtrude` / `surfaceRevolve`（直接对 **wire** 做 `BRepPrimAPI_MakePrism` / `MakeRevol`，不转面、不封顶）、`loftRobust(wires, isSolid=false)`（放样曲面）与 `loftSections(sections, isSolid=false)`（扫描曲面，复用实体扫描的平行移动标架路径）与 `faceFromPoints`；曲面体累积在引擎 `ctx.surfaces`，末尾与实体合成一个复合形状供三角化渲染。`stats.surfaces` 上报曲面体数量，设计树据此显示「曲面实体」文件夹。**体积只由实体贡献**（`solidVolume`），表面积取全体（`surfaceArea`）。
- **差异**：🟢 已具备 SW 曲面建模的主干能力（拉伸/旋转/平面区域/放样/扫描 + 曲面实体文件夹）；边界曲面/填充（平面区域已有近似）/偏移/延展/裁剪/缝合/加厚 等其余曲面命令暂未实现（加厚/偏移已实测本 opencascade.js 绑定对开放壳不可用，见第十一轮记录）。

#### 第十四轮（薄壁特征 Thin Feature）
44. **薄壁特征（SW「薄壁特征」分组）**：`ExtrudeFeature.params` 新增 `thin?: ThinSpec`（`type` 单向 /
    两侧对称 / 两侧不对称 + `thickness` + `thickness2?` + `reverse?`）。语义与 SW 一致：把草图轮廓
    **沿平面内法向偏置成带状**再成形——开环轮廓 → 一条带；闭环轮廓 → 环带（壁厚沿轮廓法向）。
45. **引擎新增 `offsetPathMiter()` + `thinProfileFaces()`**：平面内**斜接（miter）偏置**——每个顶点沿
    角平分线偏移 t 并乘 `1/cos θ` 补偿折角（系数封顶 4×，防尖刺），光滑点自动退化为法向偏移；闭环轮廓
    用外环 + 反向内环 `faceWithHoles` 挖孔成环带，开环轮廓双侧偏置首尾相接拼成闭合带面。厚度映射：
    单向 = 单侧 t（`reverse` 换侧）；两侧对称 = 各 t/2；两侧不对称 = 正 t + 反 t₂。

    而非 1760）。另用 `signedArea` 把多边形统一成逆时针，保证 `t>0` 恒为朝外。
